## 5. Current problem to solve

The site is much cleaner and more complete, but it still risks feeling too static and text-led.

Specific concerns:

1. The homepage hero is still fundamentally text plus one static image.
2. The scenario rail is currently the only strongly visible motion moment.
3. Most other sections rely on generic reveal and hover responses.
4. Internal pages share one common hero composition and may feel interchangeable.
5. Several pages may need stronger image-led or system-led visual moments below the hero.
6. Motion should increase clarity and memorability without turning a local handyman site into an agency, SaaS or technology showcase.

The goal is not “more animation.”

The goal is a more alive, premium and specific experience.

## 9. Proposed Local Repair Pro motion language

Review and refine the following candidate motion system.

Use no more than six named effect classes across the site.

### 1. Frame Set

Purpose:

Bring the homepage image, architectural frame and copy into final alignment at first load.

Possible behavior:

- all content visible immediately;
- image or frame offset by 8–12 px;
- no blur;
- no large scale;
- 500–750 ms;
- static final state for reduced motion.

### 2. Scope Trace

Purpose:

Show that a visual detail is being identified or organized.

Possible use:

- one short architectural line;
- corner mark;
- measurement-like rule;
- active service-row edge;
- process connection.

No continuous looping line.

### 3. Detail Settle

Purpose:

Bring a project image or field-note panel into its final place when it becomes relevant.

Possible behavior:

- 6–10 px movement;
- near-final opacity;
- one image at a time;
- no blur or scale spectacle.

### 4. Process Sequence

Purpose:

Clarify `describe → add context → location → scope review`.

Possible behavior:

- sequential active marker;
- no hidden content;
- no forced user interaction;
- static ordered fallback.

### 5. Surface Handoff

Purpose:

Make transitions between paper, navy and forest sections feel intentional.

Possible behavior:

- local boundary marker;
- small color-field alignment;
- no background scrubbing or full-screen wipe.

### 6. Scenario Rail

Retain the existing rail as the only continuous motion element.

Audit:

- speed;
- card scale;
- duplicate-loop seam;
- mask strength;
- pause behavior;
- mobile swipe comfort;
- whether 64 seconds is too slow, too fast or correct.

Return a final approved motion vocabulary with exact names, uses and prohibitions.
