# Adaptation Checklist

Use this checklist when onboarding a real client. Collect all of this
information before starting the adaptation of the demo to their business.

---

## 1. Business identity

- [ ] Business name (exact, as it should appear on the site)
- [ ] Logo file (SVG or PNG preferred, transparent background)
- [ ] Brand colors (hex codes if known, or examples)
- [ ] Phone number (primary)
- [ ] Email address (for contact and estimates)
- [ ] Physical address or general service-area location
- [ ] Google Business Profile URL (if they have one)
- [ ] Social profiles (Facebook, Instagram, Yelp, NextDoor, etc.)
- [ ] Preferred contact method for customers (call, text, email, form)

---

## 2. Services

- [ ] List of primary services offered
- [ ] Services explicitly NOT offered (to set expectations)
- [ ] Highest-value or highest-margin services (to emphasize)
- [ ] Emergency or urgent services? (yes/no)
- [ ] Residential, commercial, or both?
- [ ] Minimum job size or project type limitations?
- [ ] Any specialty or niche services worth highlighting?

---

## 3. Proof / trust materials

- [ ] Real project photos (minimum 5–10; more is better)
- [ ] Before and after photos (high value)
- [ ] Reviews or testimonials (exact text, do not fabricate)
- [ ] Google review link
- [ ] License or certification details (include ONLY if factually true)
- [ ] Insurance information (include ONLY if factually true)
- [ ] Years in business (include ONLY if factually true)
- [ ] Team photos or owner photo (optional but helpful)

---

## 4. Location and service area

- [ ] Primary city (main location for business)
- [ ] All cities or areas served (list each one)
- [ ] Maximum travel distance or radius
- [ ] Specific neighborhoods to mention (optional)
- [ ] Cities or areas where they do NOT want to work
- [ ] City pages to create (decide together which cities get their own page)

---

## 5. Estimate / request flow

- [ ] Preferred contact method for new estimate requests
- [ ] Phone number for calls and texts
- [ ] Email for estimate requests
- [ ] Form fields needed (what information is most useful to receive)
- [ ] Photo instructions for customers
- [ ] Typical response time (1 business day? Same day?)
- [ ] Scope of estimate: do they need photos before booking a visit?
- [ ] Typical project timeline from first contact to start
- [ ] Any projects that require an in-person visit before estimating?

---

## 6. Content replacement map

Map each demo page to the equivalent for this client:

| Demo page | Client page | Notes |
|---|---|---|
| Homepage | Homepage | Replace name, tagline, services, cities, CTA |
| Services | Services | Replace with client service list |
| Work Examples | Project Gallery | Replace with real client photos |
| Service Area hub | Service Area | Replace cities with real service area |
| City pages (×N) | City pages | Create one per agreed city |
| Request Estimate | Request/Contact | Adjust fields to client workflow |
| FAQ | FAQ | Update questions to match client's actual FAQ |

---

## 7. Launch checklist

Complete this before making the site public:

- [ ] Domain purchased and pointing to hosting
- [ ] Hosting configured and site deployed
- [ ] All contact forms tested — submissions are received
- [ ] Form notifications going to the right email/phone
- [ ] Google Analytics or similar installed
- [ ] Google Search Console set up and site submitted
- [ ] Google Business Profile updated with website URL
- [ ] Sitemap submitted to Search Console
- [ ] robots.txt reviewed
- [ ] `noindex` / `nofollow` removed ONLY when the site is ready to be public
- [ ] All placeholder content replaced with real content
- [ ] All phone numbers and emails tested
- [ ] Site reviewed on mobile (phone and tablet)
- [ ] Site reviewed on desktop
- [ ] All links tested (no broken links)
- [ ] Client reviewed and approved before launch

---

## Notes for Ihor / Примітки для Іхора

> - Збери все з цього списку ДО початку роботи. Це заощадить
>   час і питання в процесі.
>
> - Фото — найважливіше для Proof/Trust секції. Якщо клієнт
>   каже "у мене немає фото" — поясни, що можна почати без них
>   і замінити пізніше, або запропонуй прості заглушки.
>
> - noindex/nofollow прибирай ТІЛЬКИ коли клієнт підтвердив,
>   що сайт готовий до публікації.
>
> - Не запускай сайт без тесту форм. Це одна з найчастіших
>   проблем — форма не надсилає або надсилає в спам.
