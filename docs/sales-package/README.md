## What this demo is

This is a fully built, client-ready website sample for local-service businesses.
It demonstrates what a professional local-service website looks like when it is
built with a clear structure — not just dropped into a generic page builder.

The demo is for a handyman business serving Vancouver, WA and the Portland, OR
area. The structure, pages, and flow are reusable for any local-service business.

## What the demo includes

| Page | URL | Purpose |

| Services | `/services/` | Organized service categories |

## How to use this package

| File | Use for |
|---|---|
| `client-demo-walkthrough.md` | Script for showing the demo live or via screen share |
| `client-facing-one-pager.md` | Copy-paste text for email, Telegram, or PDF |
| `outreach-templates.md` | Short messages for finding clients |
| `offer-packages.md` | Three clear package options |
| `adaptation-checklist.md` | What to collect before starting a real project |
| `upsells-and-automation.md` | Add-on services and automation ideas |
| `client-objection-handling.md` | Responses to common pushback |

## Recommended sales flow

1. **Find a prospect** — Google Maps, Facebook groups, referral, cold outreach
2. **Send a short outreach message** — use `outreach-templates.md`
3. **Show the demo** — use `client-demo-walkthrough.md`
4. **Send the one-pager** — use `client-facing-one-pager.md`
5. **Propose a package** — use `offer-packages.md`
6. **Collect information** — use `adaptation-checklist.md`
7. **Discuss automation upsells** — use `upsells-and-automation.md`
8. **Handle objections** — use `client-objection-handling.md`

## Core positioning

This is not "just a website."

It is a local-service website **structure** — built with:
- A premium, trustworthy first impression
- Organized service pages
- Visual proof (project/work examples)
- Local SEO city pages
- A structured estimate request flow
- FAQ that reduces pre-sale friction
- Mobile-first CTAs
- Optional automation layer (forms, notifications, CRM, AI)

The value is not the technology. The value is the **structure, strategy, and
implementation** — done for the business owner so they do not have to figure
it out themselves.
