# Price Sheet — Local-Service Website Packages

*Starting ranges — final pricing confirmed after scope review.*

> **Note:** All prices below are starting ranges, not fixed quotes.
> Final pricing depends on scope, content, number of pages, automation
> requirements, and client-provided materials.

---

## Packages

| Package | Starting Range | Best For |
|---|---|---|
| Starter Local Website | **$1,500–$2,500** | First website, small footprint, quick launch |
| Trust Website | **$3,500–$5,500** | Professional presence + local SEO structure |
| Website + Lead System | **$6,500–$10,000+** | Full site + automation + lead handling |

---

## Package 1 — Starter Local Website

**Starting range: $1,500–$2,500**

### Includes
- Homepage with service summary, CTA, and footer
- Services section or dedicated Services page
- Contact / Request page
- Mobile-friendly layout
- SEO titles and meta descriptions
- Google Business Profile link (if available)

### Not included
- Work Examples page
- City-specific landing pages
- FAQ page
- Structured estimate intake form
- Automation or lead handling

---

## Package 2 — Trust Website

**Starting range: $3,500–$5,500**

### Includes everything in Package 1, plus:
- Dedicated Services page (organized categories)
- Work Examples / Project Gallery page
- Service Area hub page
- 3–5 City / Location pages
- FAQ page
- Structured Request Estimate page
- Stronger trust sections on homepage
- Footer with full sitemap
- Mobile sticky CTA
- Stronger local SEO page structure

### Not included
- Automation or CRM integration
- AI assistant or chatbot
- Paid ads setup
- Ongoing maintenance (unless agreed separately)

---

## Package 3 — Website + Lead System

**Starting range: $6,500–$10,000+**

### Includes everything in Package 2, plus:
- Structured estimate form with email notifications
- Lead logging (Google Sheet or simple CRM)
- Missed-call SMS follow-up setup
- Optional AI email/SMS assistant (drafts replies for human review)
- Optional chatbot / site assistant
- Review request workflow
- Basic lead reporting

### Not included
- Paid ads setup or management
- Ongoing content creation
- Advanced CRM pipeline management (available separately)
