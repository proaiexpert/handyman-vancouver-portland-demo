## Notes for Ihor / Примітки для Іхора

> - Не кажи "ваш сайт поганий" або "у вас немає нормального сайту".
>   Завжди м'який підхід: "можна зробити сильнішим", "можна покращити".
>
> - Спочатку відправ демо-посилання. Дай людині побачити самому.
>   Якщо запитають — тоді поясни деталі.
>
> - Якщо пишеш по-українськи або по-російськи — адаптуй шаблон B.
>   Якщо по-англійськи — використовуй шаблон A або C залежно від каналу.
>
> - Follow-up (шаблон D) — через 3-5 днів, якщо не відповіли.
>   Одне повідомлення. Без тиску.
